Program Linear

Beranda / KB4

1. Materi

  • Model matematika: ubah soal cerita ke kendala ax+by ≤ c, x ≥ 0, y ≥ 0.
  • DHP: daerah himpunan penyelesaian (irisan semua kendala).
  • Nilai optimum selalu di titik sudut DHP — uji semua titik sudut ke fungsi tujuan z.
  • Garis selidik: z = ax+by → y = −(a/b)x + z/b.

Contoh soal (dibahas tuntas)

Soal: Maksimumkan z = 3x + 2y dengan kendala x + y ≤ 4, x ≥ 0, y ≥ 0.

1. Titik sudut DHP: (0,0), (4,0), (0,4). 2. Uji z = 3x+2y: (0,0) → 0 (4,0) → 12+0 = 12 (0,4) → 0+8 = 8 3. Maksimum 12 di titik (4,0). ⇒ Jawaban: 12.

2. Grafik (bantu garis kendala)

Gambar garis kendala, misalnya x + y = 4 → ketik 4-x.
