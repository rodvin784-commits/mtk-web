KB 2 • Fungsi Kuadrat

Fungsi Kuadrat: f(x) = ax² + bx + c

Beranda / KB2

1. Materi

  • Bentuk umum: f(x) = ax² + bx + c, a ≠ 0. Grafiknya berbentuk parabola.
  • a > 0 terbuka ke atas (punya nilai minimum), a < 0 terbuka ke bawah (maksimum).
  • Diskriminan D = b²−4ac: D > 0 dua pembuat nol, D = 0 menyinggung sumbu-X, D < 0 tidak memotong.
  • Sumbu simetri: x = −b/2a. Titik puncak: (xp, f(xp)).

Contoh: f(x) = x²−4 → a=1, b=0, c=−4. D = 16 → dua nol di x = ±2. Puncak (0,−4). f(2) = 0.

2. Grafik Fungsi (offline, canvas)

Ketik rumus lalu tekan Gambar. Tulis kali dengan * dan pangkat dengan ^. Coba parabola: x^2-4, x^2-4*x+3, -x^2+5.

Atur rentang sumbu-X (tidak wajib)

3. Contoh Soal (dibahas tuntas)

Soal: Diketahui f(x) = x² − 4x + 3. Tentukan pembuat nol, sumbu simetri, dan titik puncak.

1. Pembuat nol: x²−4x+3 = 0 → (x−1)(x−3) = 0 → x = 1 atau x = 3. 2. Sumbu simetri: x = −b/2a = 4/2 = 2. 3. Titik puncak: xp = 2 → yp = 4−8+3 = −1 → (2,−1).

Soal 2: f(x) = x² − 4. D = 0+16 = 16 > 0 → dua nol di x = ±2, puncak (0,−4).
