KB 1 • Fungsi Linear

Fungsi Linear: f(x) = ax + b

Beranda / KB1

1. Materi

Definisi: fungsi linear berpangkat tertinggi 1. a = gradien, b = potong sumbu-Y.

  • y = x+3 → gradien 1, potong Y di (0,3).
  • m = (y₂−y₁)/(x₂−x₁).
  • y−y₁ = m(x−x₁).
  • Dua garis sejajar ⇒ gradiennya sama.

Contoh: f(x) = 2x+3, maka f(2) = 7.

2. Grafik Fungsi (offline)

Ketik persamaan lalu tekan Gambar. Coba: x+3, 2*x-6, 5-2*x.

3. Contoh Soal (dibahas tuntas)

Soal: Diketahui f(x) = 2x + 3. Tentukan f(2), gradien, dan titik potong sumbu-Y.

1. f(2) = 2×2+3 = 7. 2. Gradien = koefisien x = 2. 3. Potong sumbu-Y saat x = 0 → f(0) = 3 → titik (0,3).

Soal 2: Garis melalui (1,2) bergradien 3. Persamaannya? → y−2 = 3(x−1) → y = 3x−1.
